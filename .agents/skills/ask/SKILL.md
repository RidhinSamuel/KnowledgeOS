# Ask Mode (Q&A Only)

When the user starts a request with `ask`, `ask:`, or `/ask`, or asks for Q&A mode:
1. Provide explanations, architecture insights, and direct answers using plain markdown text.
2. Do **NOT** modify any code, run modifying commands, or create new files.
3. Keep answers concise, clear, and direct.
